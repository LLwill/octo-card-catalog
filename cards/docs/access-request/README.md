# docs.access-request

Mutable source package for the document access request Card.

Pull requests that change this directory run the pinned `card-check` Action.
Download the generated workflow artifact and open `preview/index.html` to inspect
the self-contained Forge Web preview backed by its preview-channel Catalog
Snapshot.

Published versions live under `versions/<version>` and remain immutable after
their release tag is created.
